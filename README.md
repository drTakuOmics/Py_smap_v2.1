# Py_smap_v2.1 — Python/PyTorch port of SMAP v2.1

`smap/` is a one-to-one Python/PyTorch translation of SMAP v2.1's `smappoi_search_global`
(high-resolution 2D template matching: global search, clustering, refinement and the final
optimisation), checked against the original MATLAB code executed in Octave.

Original method and code: **SMAP v2.1, J. Peter Rickgauer, HHMI Janelia**
(https://github.com/jpr-smap/smap_v2.1, MIT License). Please cite Rickgauer et al., eLife 2017;
Rickgauer et al., bioRxiv 2020; Lucas et al., eLife 2021. The upstream README, including the
description of every `.par` parameter and output file, is kept in
[docs/SMAP_v2.1_README.md](docs/SMAP_v2.1_README.md).

## Install

```bash
# PyTorch first: CUDA build for a GPU workstation (see pytorch.org), or CPU-only:
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -e ".[test]"
```

## Run

```bash
# the bundled sample (its .par uses the upstream Docker paths /opt/smap/...)
python -m smap.search_global sample_search.par --path-map /opt/smap=. \
       --output-dir results/sample --batch-size 8 --log results/sample_run.log

# compare two output folders (v2.1 vs port, CPU vs GPU, batch 1 vs 8)
python -m smap.compare <reference_output> <test_output> --json report.json
```

Outputs keep the v2.1 names and formats (`list_final.txt`, `particles.{txt,par,mrc}`,
`templates.mrc`, `search_*.mrc`, `search_SH.txt`, `highVals.txt`, …) plus `search_status.json`
(completeness, score definitions, input hashes, code version) and `particles.csv` with
`particles_schema.json`.

Additional tools (new, not in v2.1):

```bash
# target-decoy FDR: run the same .par again with "decoy_template mirror" (or
# "decoy_image phase_random") and compare final-score counts
python -m smap.decoy --pair <target_output> <decoy_output> --cutoff 8 --out decoy_calibration

# RELION 3.1+/cryoSPARC particle STAR for baited reconstruction
python -m smap.export smap <output> --micrograph mic.mrc --offset X0 Y0 --images -o particles.star
python -m smap.export rnf213 all_candidates_registration.csv --par <tile>/search.par --micrograph NAME -o particles.star
```

The search also writes full-image MIP maps and a p-value map (`search_mip*.mrc`,
`search_pval.mrc`; anisotropic-Gaussian p-value of Zhang et al., IUCrJ 2025, as in Leopard-EM).

RNF213 project (existing v2.1 tile trees, unchanged review scripts): see
[docs/RNF213_RUN.md](docs/RNF213_RUN.md) (`tools/rnf213_port_tiles.py`, `tools/gpu_smoke.py`).

All behaviour changes relative to v2.1 are opt-in `.par` keys; with none of them set the port
reproduces v2.1, including its known quirks. See [PORT_NOTES.md](PORT_NOTES.md) for the status,
command-line flags, options, tests and the list of v2.1 behaviours found during the port.

## Repository layout

| Path | Contents |
|---|---|
| `smap/` | the port: `search_global` (setup, search, combine, CLI), `refine` (clustering, refinement, optimisation, final files), `structure` (PDB/CIF → scattering potential), `ctf`, `grid`, `rot`, `utils`, `io`, `stats`, `compare`, `provenance`, `decoy`, `export`, `pvalue` |
| `tests/` | Octave-parity tests (references in `tests/refs`, generated by `tests/octave/*.octave` from the original MATLAB), synthetic end-to-end and CLI tests |
| `experiments/` | small numerical studies behind the optional improvements |
| `tools/` | RNF213 tile runner, GPU smoke test, scattering-factor table generator |
| `docs/` | upstream SMAP v2.1 README |
| `THIRD_PARTY_NOTICES.md` | licence of code adapted from Leopard-EM (BSD-3-Clause) |
| `image/`, `model/`, `rotation/`, `sample_search.par` | upstream sample data |
